# Library

Imported external captures — material **not** authored by Yago, kept as-is for reference:

- **Web clips** (e.g. Obsidian Web Clipper output)
- **Transcripts** (podcast / video / call transcripts)
- **Articles** and other long-form sources worth preserving

Distinct from the domain folders (`Career/`, `Family/`, `Finances/`, `Health/`, `Plans/`, `Self/`), which hold Yago's own living notes. Binaries (PDFs, images) go in `../assets/`.

Each capture should carry frontmatter: `type: capture`, `created`, `lang`, and `links:` to the original source URL when applicable.
